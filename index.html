    Generative AI and search

    AI-Powered Document Intelligence Assistant

    A RAG application that lets a person upload documents and ask questions about them. It retrieves the passages that match the meaning of the question, not just the keywords, and passes them to an LLM to write the answer.

    • Ingestion pipeline that turns unstructured PDFs into meaningful chunks and vector embeddings, using Sentence Transformers (all-MiniLM-L6-v2).
    • Retrieval tuned to cut irrelevant context sent to the generation layer, improving answer relevance.
    • Streamlit interface for upload, processing, question answering and generated insights.
